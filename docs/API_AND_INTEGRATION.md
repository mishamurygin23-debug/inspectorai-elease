# Спецификация интеграции с ИАС РИН и API обмена данными
### Информационно-аналитическая система управления контрольно-надзорной деятельностью Мосгосстройнадзора (ИАС РИН)

Данный документ описывает протоколы взаимодействия программного комплекса «Инспектор ИИ» с ведомственными информационными системами Правительства Москвы, формат пакета данных проверки и требования к усиленной квалифицированной электронной подписи (УКЭП).

---

## 1. Общие сведения и форматы передачи

Интеграция осуществляется через защищенный программный интерфейс (REST API) с использованием формата **JSON** для структурированных данных и стандарта **CMS / CAdES-BES** для электронных подписей.

- **Кодировка данных:** UTF-8
- **Протокол передачи:** HTTPS (TLS 1.3 с поддержкой ГОСТ Р 34.12-2015 / Кузнечик, Магма при наличии шлюза КриптоПро NGate)
- **Идентификация запросов:** Заголовок `X-Request-ID` (UUID v4) для сквозного аудита

## 3. Требования к электронной подписи (УКЭП)

В соответствии с требованиями Федерального закона № 63-ФЗ «Об электронной подписи» и регламентами Мосгосстройнадзора:
1. **Алгоритм формирования подписи:** ГОСТ Р 34.10-2012 с длиной закрытого ключа 256 бит или 512 бит.
2. **Алгоритм хеширования:** ГОСТ Р 34.11-2012 (256 бит или 512 бит).
3. **Формат подписи:** CMS Advanced Electronic Signatures (CAdES-BES / CAdES-T) с включением метки доверенного времени (TSP).
4. **Валидация:**
   - Проверка цепочки сертификатов до Головного удостоверяющего центра Минцифры РФ;
   - Проверка статуса отзыва сертификата по протоколу OCSP или актуальным спискам отзыва (CRL).

## 4. Коды ошибок API и регламент повторных попыток

| HTTP Код | Внутренний код ошибки | Описание | Действие клиента |
|----------|-----------------------|----------|------------------|
| 200 OK | `SUCCESS` | Пакет успешно принят и зарегистрирован в ИАС РИН | Отобразить номер дела проверки инспектору |
| 400 Bad Request | `SCHEMA_VALIDATION_ERROR` | Ошибка структуры JSON или неверный формат параметров | Исправить структуру запроса |
| 401 Unauthorized | `INVALID_UKEP` | Сертификат УКЭП недействителен, отозван или не совпадает с ФИО инспектора | Запросить переподписание действующим ключом |
| 409 Conflict | `OBJECT_PERMIT_MISMATCH` | Номер РНС не найден в реестре разрешений на строительство Москвы | Сверить реквизиты объекта с реестром |
| 503 Service Unavailable | `IAIS_GATEWAY_TIMEOUT` | Временная недоступность шлюза ИАС РИН | Пакет помещается в локальную очередь с экспоненциальным backoff (повтор каждые 60 секунд) |
