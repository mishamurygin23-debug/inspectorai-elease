# Дообученная нейросетевая модель «Инспектор ИИ: Поиск гипотез и коллизий» v2.4.2

Модель создана для автоматического выявления проектных нарушений и скрытых коллизий между проектной (ПД), рабочей (РД) и исполнительной (ИД) документацией объектов капитального строительства г. Москвы.

## Дообучение (Fine-Tuning)
Чекпоинт **v2.4.2-altufievo-finetuned** дообучен на реальном комплекте документов:
- **Объект:** Торговое здание по адресу: г. Москва, СВАО, Алтуфьевское шоссе, вл. 79Б, стр. 1
- **Заказчик:** ООО «ФИРМА РУСЬ ТРЕЙ»
- **Разделы:**
  - `ЖС-РЛ-270121-АР` (ПД, ООО «Жилстрой»)
  - `РД-2025-04.266-АР1` (РД Архитектурные решения, ООО «Моспроекткомплекс»)
  - `РД-2025-04.266-АР2` (РД Фасады, раскладка сэндвич-панелей, узлы)
  - `РД-2025-04.266-ОВ` (РД Отопление и вентиляция)
  - `П-2025-04-266-КЖ01` (РД Свайное поле, 364 сваи, ростверки)
  - `ИД №1-НВФ7.7.2-Кр` (Исполнительные схемы отклонений)

## Метрики качества по разделу 14 ТЗ (10 критериев приемки)
- **Character Accuracy (OCR):** 98.8% (порог >= 95%)
